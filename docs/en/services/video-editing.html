FAQ

Questions before starting the project

How is video editing priced?

Source-footage duration and organization, editing style, motion, captions, sound, versions and revisions affect the quote. We define these before pricing because finished video duration alone does not describe the workload.

What do you need to start editing?

I need the footage, logo, copy and any available visual references, together with the goal, platform and required deadline.

Can the video be delivered in multiple formats?

Yes. Horizontal, vertical and square versions can be prepared for the agreed platforms within the project scope.

How are video revisions handled?

Feedback is collected in an organized review round so the requested changes remain clear and consistent.
