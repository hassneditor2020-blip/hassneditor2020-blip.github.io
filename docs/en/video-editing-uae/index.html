FAQ

Common questions before production

Can I send footage from any emirate?

Yes. Editing and motion can be completed remotely from client-supplied material. File transfer, review, versions and formats are agreed before production.

How should I compare editing quotes?

Compare source-footage duration, sequence development, color, sound, captions, motion, versions and revisions. Use the same scope for each comparison rather than finished duration alone.
